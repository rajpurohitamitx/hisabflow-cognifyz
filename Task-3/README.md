# Task 3 — Responsive UI + CSS + Bootstrap

## Requirement covered
Advanced CSS, responsive design, transitions/animations, Bootstrap.

## HisaabFlow implementation
- Bootstrap 5 grid, forms, buttons and responsive utilities.
- `app/public/css/app.css` contains the product design system and responsive rules.
- Mobile-first dashboard and entry screen.
- Consistent status colors: green healthy, amber watch, restrained red urgent.

## UX target
A shopkeeper should be able to see outstanding money and reach “Add transaction” or “Remind” without navigating through a complicated admin menu.
