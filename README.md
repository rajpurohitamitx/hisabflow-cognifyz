# HisaabFlow application

Canonical runnable application for Cognifyz Tasks 1–6.

## Folders

- `routes/` — web and REST endpoints
- `models/` — MongoDB schemas
- `middleware/` — authentication middleware
- `services/` — follow-up rules, sentence parsing and temporary draft storage
- `views/` — EJS pages
- `public/css/` — visual design system
- `public/js/` — client-side validation, DOM updates, Fetch calls and hash routing
- `scripts/` — optional demo-data seed

The code is intentionally straightforward so each part can be explained in an interview.
