# Task 5 — REST API + CRUD + frontend fetch

## Requirement covered
REST API, CRUD operations, frontend interaction with the API.

## Endpoints
- GET/POST `/api/customers`
- PUT/DELETE `/api/customers/:id`
- GET `/api/customers/:id/transactions`
- POST/PUT/DELETE `/api/transactions...`
- GET `/api/follow-ups`
- GET `/api/dashboard`
- POST `/api/natural-language/parse`
- POST `/api/natural-language/save`

## Frontend
`app/public/js/app.js` uses `fetch()` and handles JSON success/error states.
